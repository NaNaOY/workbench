# 隐私与数据边界

WorkBench 是本地优先应用。仓库中的源码不需要账号、私有服务或个人配置才能运行。

## 本地保存

任务、笔记、快捷入口、专注统计、每日认知缓存、GitHub 榜单缓存和认知产出默认写入当前运行环境的浏览器 `localStorage`。桌面版通过 Electron preload 桥接把这份存储镜像备份到 Electron 的 `userData` 目录，文件名为 `workbench-storage.json`。

这个备份文件属于用户个人数据，不在仓库中、不进入安装包发布流程，也不应上传到 GitHub。卸载时应用默认保留数据，便于重新安装后恢复。

## 网络请求

应用只在刷新或定时更新时请求公开数据：

- 国内公开 RSS，用于每日资讯；
- GitHub REST Search API，用于干货榜。

认知提升知识卡来自应用内置的公开内容库。应用不收集遥测，不上传任务、笔记或思考内容，也不需要在仓库中配置 API 密钥。

## GitHub Pages

Pages 版本没有 Electron 主进程，不能访问桌面用户数据目录，也不会把访问者数据写回仓库。每位访问者的数据只存在自己的浏览器中。

## 贡献者检查清单

提交代码前请确认：

1. 没有提交 `.env`、本地配置、日志、`release/` 或用户数据备份；
2. 没有把 `C:\Users\...`、`D:\...` 等绝对路径写入源码、文档或截图；
3. 没有粘贴任务、笔记、账号信息、访问令牌或私有接口地址；
4. 网络请求仍然指向公开、可验证的来源。

如果发现疑似隐私泄露，请先不要在公开 Issue 中粘贴原文，改为联系仓库维护者。
