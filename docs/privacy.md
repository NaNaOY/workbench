# 隐私与数据边界

WorkBench 是本地优先应用。源码运行和桌面安装均不需要账号、私有服务、数据库或 API 密钥。

## 本地保存

以下数据默认写入当前应用环境的浏览器 `localStorage`：

- 任务、快捷入口和信息学题单；
- 个人台账的分类、记录与关键数值；
- 富文本笔记及粘贴到笔记中的图片；
- 专注记录、每日统计和热力图数据；
- 每日认知缓存、关联笔记和认知产出；
- 期货面板的自选配置与本机价格提醒；
- GitHub 榜单缓存及界面偏好。

桌面版通过受限的 Electron preload 桥接，将这份存储镜像备份到 Electron `userData` 目录中的 `workbench-storage.json`。该文件属于用户个人数据，不进入安装包，也不应上传到 GitHub、Issue 或 Pull Request。

笔记图片以内嵌数据保存，会增加本地存储体积。请定期备份重要内容，并避免粘贴包含身份证、账号凭证或其他敏感信息的截图。

## 网络请求

应用只为用户可见的联网功能请求公开数据：

- 国内公开 RSS：每日资讯；
- 国内公开网页：认知提升知识来源；
- GitHub REST Search API：GitHub 干货榜；
- 东方财富公开行情接口与日 K 图服务：期货面板报价与图表；
- Google 新闻 RSS、Wikipedia 和 Wikisource：独立的 Google 知识板块。

Google 知识板块可能需要网络代理，并与国内直达内容分开处理。应用不收集遥测，不上传任务、笔记、图片、专注记录或阅读笔记，也不会静默连接私有接口。

外部文章通过系统浏览器打开。链接会检查协议和正文路径；已知失效的旧政府文章地址会迁移到仍可定位正文的官方页面，无法确认正文的首页链接会被拒绝。

## 升级、卸载和清理

- 安装新版会替换旧程序文件，并保留用户数据；
- 卸载安装版默认不删除 `userData`；
- 便携版程序文件与用户数据可能位于不同位置；
- 如需彻底清理，请先备份，再删除应用对应的浏览器存储和 `workbench-storage.json`。

## 贡献者检查清单

公开提交前请确认：

1. 没有提交 `.env`、日志、构建产物、安装包或用户数据；
2. 没有出现用户目录、项目绝对路径、本机用户名或个人邮箱；
3. 没有任务、笔记、截图、访问令牌、账号密码或私有接口地址；
4. 网络请求只指向公开、可验证且与功能相关的来源；
5. 已运行 `npm run typecheck` 和 `npm run build`。

如发现疑似隐私泄露，请不要在公开 Issue 中粘贴原文，应先通过私密渠道联系维护者。
