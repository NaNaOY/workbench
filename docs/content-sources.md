# 每日认知内容源

每日认知分为三个彼此隔离的模块，避免国内直达内容与需要代理的海外来源相互混杂。

## 每日资讯

- 使用新华网、人民网、中国新闻网、36氪等公开 RSS；
- 按政治、思维、心理、法律、经济、商业、科技、健康和电力能源分类筛选；
- 过滤公告、招聘、招标、情绪文案和重复内容；
- 外链在打开前会校验协议、正文路径与已知失效旧地址。

## 认知提升

- 使用应用内置的知识卡内容库；
- 来源优先选择国内可直接访问的百科、经典原文、法律法规、学术期刊和机构科普页面；
- 每张卡片强调核心概念、适用场景、自测问题和方法边界；
- 旧版政府文章链接会迁移到仍可定位正文的官方页面，无法确认正文的首页链接会被拒绝。

## Google 知识

- 使用 Google 新闻 RSS 获取近期报道；
- 使用 Wikipedia 和 Wikisource 提供稳定的主题词条与经典原文卡片；
- 该模块明确标注为海外来源，在中国大陆访问时可能需要网络代理；
- Google 新闻不可达时会在 6 秒内回退到内置 Wiki 卡片，并在短时间内停止重复重试；
- 海外来源只在此模块受控放行，不会改变“每日资讯”和“认知提升”的国内直达规则。

## 更新策略

- 桌面应用启动时预取内容；
- 每天本地时间 08:00 自动更新；
- 页面支持手动更新当前模块和分类；
- 内容缓存仅保存在本机，不会上传任务、笔记或阅读记录。

外部来源的可用性、版权和内容准确性由对应网站负责。医疗、法律和投资内容仅用于学习，不构成专业意见。
